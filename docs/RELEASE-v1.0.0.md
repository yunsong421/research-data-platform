# v1.0.0 · 研究资料管理与自定义可视化

面向需要统一管理问卷、文档和访谈资料的小型研究团队，提供可在本地运行的 Flask 与 SQLite 应用。此版本源码包不含真实研究数据或预置账号。

## 功能

- 问卷、文档、学生 / 教师访谈资料管理及关键词检索。
- 支持格式的文档图片预览、音视频播放、附件下载和批量上传。
- 上传 Excel 后选择工作表、字段、统计方式与图表类型，支持六种图表和 PNG 下载。
- 按字段类型自动推荐图表配置，显示有效记录、剔除记录和类别截断情况。
- 用户登录、账号设置、首次管理员自建、数据本地存储。
- 新增 Windows 双击启动与 macOS / Linux 启动入口，提供可复现模拟工作簿和截图演示。

## 试用

安装 Python 3.11，Windows 双击 `start.bat`；macOS / Linux 执行 `sh start.sh`。首次运行需联网安装依赖，并自行设置至少 12 位的管理员密码。登录后上传 `examples/sample-survey.xlsx` 即可体验六种图表。

## 使用边界

- 固定问卷分析页依赖原有表头；通用 Excel 请使用“自定义可视化”。
- 不自动拆分多选题，不执行显著性检验、相关性推断或因果分析。
- 登录用户共享当前部署的数据，不提供项目级权限隔离。
- 不是静态网站，不能通过 GitHub Pages 直接运行；Docker 构建及公网安全仍需部署方验证。
- 未授予开源许可证；发布授权由代码权利人决定。

截图和工作簿均为程序生成的虚构示例，不代表真实研究结论。
