# 数据说明

仓库额外提供 `examples/sample-survey.xlsx`，它由 `examples/generate_sample.py` 确定性生成，只包含虚构问卷和模拟月度汇总，不含真实受访者资料。`docs/images/` 中三个白名单展示文件也只使用这份模拟数据。示例不会自动导入数据库；首次启动仍为空库。除这些逐一列出的展示文件外，上传文件、图表和研究数据仍默认排除。

“自定义可视化”将上传的 Excel 工作表转为结构化 JSON 存入 `chart_datasets` 表，第一行作为表头，空表不导入，重复表头会加序号。保存公式的缓存值，不执行宏和公式；没有缓存值的公式按空值处理。原文件不另行存档。已有文档中的 `.xlsx` 可以只读选用，不会被这里的删除功能移除。所有运行时数据集仅保存在部署者的 SQLite 中，发布包不含已导入的数据库。

首次启动自动建立空表。SQLite 使用 WAL，文件、视频采用 BLOB 保存，因此数据库备份也包含附件和账号密码哈希，须按私人资料保管。备份宜使用 SQLite backup API 或停服后的完整备份。

新增 `trash_entries` 表保存删除记录的字段、附件和标签快照。普通删除只从活动列表移出并进入回收站，磁盘占用不会因此下降。恢复保留原 ID；ID 被新记录占用时生成新 ID，绝不覆盖新记录。彻底删除移除回收站副本，但手动 / 自动备份可能仍保留历史内容。

`wsgi.py` 启动时进行每日备份并每小时检查，自动备份最多 7 份；手动及恢复前备份单独保留，位于 `DATA_DIR/backups/`。用相同 `DATA_DIR`、停止所有数据库访问进程后运行 `restore_backup.py` 进行整库恢复。此工具会先创建当前状态的 `before-restore` 备份。当前 session 密钥不在数据库备份内，原文件不要删除；账号随数据库回到备份状态。

问卷管理支持“答卷数据表”和“问卷列表”导入。前者将每个非空工作表存入对应问卷 `content.survey_table`，保留表头与结构化单元格值；题目、预览、表格下载和自定义可视化均读取各自问卷的数据，回收站也一并保存。后者接受平台导出的元信息及 `content`，需有标题列；没有有效记录时返回错误，不再提示导入 0 条成功。数据表下载重新生成 `.xlsx`，不保留原排版和公式。原专题分析仍读取 `documents` 中 `category='source'` 的第一条 Excel 记录；没有独立数据的旧问卷仍兼容此源。发布版不附带源文件，也不自动扫描本地 Excel。

接入自己的调查时，应在独立部署环境建立问卷及对应源文件，并适配 `app.py` 中的列名和文本选项。数字答案须以经核实的编码表转换。预览显示前30行，源文件下载包含完整数据。无源文件时分析页显示暂无数据。

`.gitignore` 默认忽略所有文件，只允许指定源代码与说明文件。数据库及 WAL/SHM、备份、密钥、日志、问卷表格、报告、图片、音视频及压缩包默认均被忽略。规则不能清除已追踪文件，禁止用 `git add -f` 强行加入私人资料。手动粘贴到源代码中的个人信息仍须在提交差异中检查。
