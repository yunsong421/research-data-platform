# 模拟数据

`sample-survey.xlsx` 由固定随机种子程序生成，**全部为虚构数据**，不对应任何真实学校、受访者或研究结论。它包含 120 条模拟问卷和 6 条模拟月度汇总；仅用于熟悉上传、选字段及生成图表的操作。

启动网站并登录后，进入“自定义可视化”，上传这个文件。两个工作表会各自成为数据集，不会覆盖已有问卷、文档或访谈。

| 图表 | 数据集 | 分类 / 横轴 | 数值字段 | 统计方式 |
| --- | --- | --- | --- | --- |
| 横向条形图、柱状图、饼图 | 模拟问卷 | 专业类别 | 无 | 记录数 |
| 直方图 | 模拟问卷 | 城市认同得分 | 无 | 无需选择 |
| 散点图 | 模拟问卷 | 城市认同得分 | 就业意愿得分 | 无需选择 |
| 折线图 | 模拟月度汇总 | 月份 | 参与人数 | 合计 |

默认“自动选择”优先识别较少类别的字段并推荐条形图；这是字段类型规则推荐，不代表统计推断或人工智能分析。所有选择均可手动调整。示例中的分值关联也是程序人为设定，不应作为实证发现引用。

可重新生成示例：

```bash
python examples/generate_sample.py
```

只允许这个明确命名的模拟工作簿进入公开仓库。自己的 Excel、数据库、视频、文档和导出图表仍应保存在被忽略的私有目录中。
